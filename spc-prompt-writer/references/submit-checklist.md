# SPC 提交前检查清单

逐项确认后再提交：

- [ ] Prompt 文本在 **10,000 字符**以内
- [ ] 输出格式要求明确指定为**纯 JSON**
- [ ] JSON 格式示例正确（`"ISIN|MIC": weight`）
- [ ] 信心分范围明确说明为 **−1 到 1**
- [ ] 已要求使用**最低温度**设置（或 temperature 0）
- [ ] 已明确要求**搜索网页**（非内部记忆）
- [ ] 股票池 / 覆盖范围已定义
- [ ] 没有模糊词汇（strong / robust / good）
- [ ] 没有要求散文 / markdown / 解释输出
- [ ] 没有使用 ticker 代码（用 `ISIN|MIC`）
- [ ] 样本输出（Sample Output）已实测通过
- [ ] 权重设置合理（0–1.0，两位小数）
- [ ] 更新频率已选择（原帖清单原文止于此），且 **⛔ 首字母小写**：`daily` / `weekly` / `monthly` / `quarterly`（跟帖修正）
- [ ] 已在**新对话**中做最终测试（避免上下文污染）

## 提交后（非原帖清单内容，摘自原帖 §十二 / §十三）

- 活跃（权重 > 0）prompt 总数 ≤ **50**；每天创建 ≤ **50** 个。
- Prompt 文本提交后**不可编辑**；只有权重可改，且下一个频率周期生效。
- 撤回 = 权重设 0。
